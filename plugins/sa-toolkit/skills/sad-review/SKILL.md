Ensure architecture is based on good architectural patterns

1. Check architecture is compliant with the target architecture specified on confluence page https://wiki.tools.nykredit.it/spaces/EA/pages/231017655/Target+Architecture and subpages
2. Check architecture is focused on clean architecture, maintainability, security and separation between services and user interface
3. Check business rules, including validation and calculation is placed in the services
4. Check if architectural documentation is written in clear and easy understandable English
